# Incident Response Playbooks Collection

## Overview
Bộ tài liệu Quy trình Ứng cứu Sự cố (Incident Response Playbooks) được biên soạn theo chuẩn **NIST SP 800-61 Rev. 2**, nhằm cung cấp hướng dẫn từng bước cho SOC Analysts (Tier 1/2) trong việc Phát hiện, Cô lập, Triệt hạ và Khôi phục hệ thống khi gặp sự cố an ninh mạng.

## Included Playbooks
1. [Phishing Incident Response Playbook](./IR-Playbook-Phishing.md)
2. [Ransomware Incident Response Playbook](./IR-Playbook-Ransomware.md)
3. [Brute-Force & Password Spraying Playbook](./IR-Playbook-BruteForce.md)
4. [Web Shell & Web Application Attack Playbook](./IR-Playbook-WebShell.md)

## Methodology
Mọi Playbook đều tuân thủ 4 giai đoạn chuẩn của NIST:
1. Preparation
2. Detection & Analysis
3. Containment, Eradication & Recovery
4. Post-Incident Activity
